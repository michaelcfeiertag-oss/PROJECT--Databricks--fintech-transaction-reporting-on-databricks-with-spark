# Expected Outputs

Students should produce the following final reporting outputs.

## 1. Daily transaction summary
Suggested columns:
- report_date
- total_transactions
- total_amount
- successful_transactions
- failed_transactions
- avg_amount

## 2. Failed transaction summary
Suggested columns:
- report_date
- transaction_type
- payment_channel
- failed_count
- failed_amount

## 3. High-value transfers
Suggested columns:
- report_date
- account_id
- customer_id
- transaction_id
- amount
- transaction_type
- payment_channel
- merchant_country

## 4. Payment channel summary
Suggested columns:
- report_date
- payment_channel
- transaction_count
- total_amount
- avg_amount

## 5. International transaction summary
Suggested columns:
- report_date
- merchant_country
- transaction_count
- total_amount
